
# 🏛️ SchemeWise – Government Scheme Eligibility Checker

## 🚀 Features

- 🔍 Eligibility Checker  
  Enter age, income, category, and occupation to find matching schemes  

- 📋 Detailed Scheme Info  
  View benefits, eligibility, and ministry details  

- 🔗 Direct Apply Links  
  Open official portals and apply instantly  

- ❤️ Wishlist  
  Save schemes for later  

- ✅ Applied Tracker  
  Track applied schemes  

- 🕓 Recent Activity  
  View recently opened schemes  

- 💬 Chatbot Assistant  
  Ask about schemes, documents, and process  

- 🔐 Login/Register (Frontend)  
  Uses localStorage (no backend auth)

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend: Python (Flask)  
- Storage: Browser LocalStorage

## 🧪 How It Works

- User enters:
  - Age  
  - Income  
  - Category  
  - Occupation  

- System filters schemes based on:
  - Age range  
  - Income limit  
  - Category  
  - Occupation  

- Displays eligible schemes with apply links
